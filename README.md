# איי הזהב

משחק אסטרטגיה ימי לאנדרואיד: מיישבים איים, בונים מבנים וספינות, נלחמים בשודדים וקונים איים של יריבים.

- קוד המשחק: `web/index.html` (HTML + JavaScript, ציור על Canvas, צלילים נוצרים בקוד).
- עטיפת אנדרואיד: `app/` (WebView).
- בנייה: כל דחיפה ל-`main` מריצה את GitHub Actions ובונה APK. הקובץ נמצא בלשונית Actions, תחת Artifacts.
- גרסה: `def vName` בקובץ `app/build.gradle`.
- חתימה: `keystore/release.jks`. אותו מפתח בכל בנייה, כדי שכל גרסה תותקן כעדכון על הקודמת. אסור למחוק אותו.
